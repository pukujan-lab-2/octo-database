## Goal

Capture every visible user and assistant message from the shared conversation, in order and verbatim, with a deterministic manifest proving what was captured and preventing silent rewriting.

## Success condition

- source URL preserved exactly;
- every visible turn/message captured in order;
- no spelling cleanup, summarization, normalization, or reconstructed missing text;
- capture is rescanned end-to-end;
- message/turn count recorded;
- SHA-256 of transcript recorded;
- capture timestamp/method recorded;
- immutable source file committed;
- later recapture creates a new version instead of editing original in place;
- incomplete/inaccessible page is reported as incomplete rather than claimed complete.

## SDD / artifact design

Suggested files:
- planning/source/chatgpt-storage-platform-transcript-v1.md
- planning/source/chatgpt-storage-platform-transcript-v1.manifest.json

Manifest fields: source_url, captured_at, capture_method, visible_message_count, optional user/assistant counts, sha256, completeness_status, notes/limitations, supersedes.

The transcript itself is immutable evidence. Planning documents cite it but never mutate it.
