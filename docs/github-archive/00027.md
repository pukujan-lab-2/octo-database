## Summary

Delivers the private workspace gallery: responsive thumbnail grid, modal lightbox, and browser video playback over the existing workspace/file APIs.

## Verified behaviour
- **Thumbnail/full separation proven in a browser**: grid loads a 400x300 WebP derivative; opening the item loads the 1000x700 original. No failed requests.
- **Derivative is real and idempotent**: `derived/{file_id}/thumb.webp` written exactly once across repeated calls (306 B vs 16032 B original in the live run).
- **Signed media URLs**: image/video tags cannot send Authorization headers, so media URLs carry a short-lived HMAC signature scoped to one file + workspace + principal; membership is re-checked on every use. Unsigned and forged requests return 401.
- **Cross-workspace isolation**: an unauthorized principal receives FORBIDDEN for another workspace's media.

## Defects found and fixed during verification
- **Binary upload corruption**: uploads stored base64 *text* as the object body (21376 B stored vs 16032 B original). Payloads now declare `dataEncoding` and are decoded before storage; PNG magic bytes verified intact.
- **Self-referential download URL**: the local fallback returned the same `/api/files/download` endpoint that produced it. Replaced with a real `/api/files/content` route that streams bytes.
- **Silent local fallback removed**: storage now requires explicit `OCTO_STORAGE_BACKEND=local` (CI/dev only); production still fails closed without R2.
- **Dead Google CTA**: the button pointed at a nonexistent `/api/auth/google`. The server now implements the redirect and reports a clear not-configured state when no OAuth client is set.
- **`.env.example` name drift**: documented names now match what `loadR2ConfigFromEnv` actually reads.
