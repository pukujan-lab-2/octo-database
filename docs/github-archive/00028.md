## Problem

Fork pull requests never receive repository secrets, so `INFERHUB_API_KEY` is absent there by design. The vision assertions would fail any fork PR on a dependency that cannot be satisfied — blocking external contributions permanently.

## Change

- Extracted the audit into `tests/e2e/vision-audit.ts`.
- When the key is unavailable, the audit is skipped and the reason is logged explicitly rather than failing silently.
- Same-repo runs (every push to `main` and every owner branch) still perform the real audit and assert the score.
- Playwright E2E is therefore no longer an unsatisfiable required check for forks, and `pull_request_target` is deliberately not used, since checking out untrusted PR code with secrets is the standard exfiltration footgun.

## Verification

Local run with the key present: all 3 E2E specs pass, with the vision audit reporting model, score, and notes for both the login screen and the dashboard.
