## Summary

Resolves residual security and hygiene gaps across the server runtime and schema:
- **UUID Validation**: `DELETE /api/keys/:id` now validates `UUID_PATTERN` and returns a clean 400 instead of surfacing Postgres cast errors as 500s.
- **Worker Outcome Isolation**: `/api/jobs/run?workspaceId=...` now filters outcomes so only jobs belonging to the caller's authorized workspace are returned.
- **Grant Hardening**: Removed client-side `EXECUTE` grant on `octo.claim_job` so only the trusted server role can claim background jobs, preventing denial-of-service job-state flipping by arbitrary authenticated sessions.
- **Error Clarity**: Updated RAG endpoints to reference `OCTO_EMBEDDING_API_KEY` instead of the stale InferHub key reference.
- **Share Resource Validation**: `POST /api/workspaces/shares` rejects non-gallery resource types until albums/folders are explicitly modeled.
