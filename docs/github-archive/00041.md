## Summary

Wires the frontend Archive and Restore actions to the backend endpoints implemented in PR #39:
- **Dashboard UI**: Added `Storage Tier` table column with status badges:
  - `Drive (Cold)` (`info` outline) for `archived_drive`
  - `R2 (Active)` (`success` outline) for active files
  - `Archiving...` / `Restoring...` (`warning` outline) for in-flight jobs

- **Actions**: Shows contextual `Restore` button for archived files and `Archive` button for active files alongside existing `Delete` button.
