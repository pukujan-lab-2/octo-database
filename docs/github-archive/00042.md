# Issue #42: Host Octo on gravebuster with a production branch and gated CI/CD

- State: closed (2026-10-01)
- Opened by Pukujan on 2026-10-01
- Original: https://github.com/Pukujan-lab/octo-database/issues/42

## Goal

Host Octo's frontend and backend as containers on gravebuster, reachable at
`octodb.design-bakery.com` through the existing Cloudflare tunnel, with a
CI/CD path that cannot break the running service and a `production` branch the
owner promotes to deliberately.

## Blocking defects found

1. **Google sign-in is broken, not merely unconfigured.** `src/server/index.ts:465`
   redirects to Google with `redirect_uri=${url.origin}/api/auth/google/callback`,
   but no route handles that callback. The full route list has `/api/auth/google`
   and `/api/auth/guest` only.
2. **The server serves no frontend.** `src/server/index.ts` is API-only
   (`/api/*`, `/health`); Vite builds `dist/` but nothing serves it.
3. **The redirect URI is origin-relative.** `url.origin` derives from the
   hardcoded `http://localhost:${PORT}` base (`index.ts:436`); nothing reads
   `X-Forwarded-Host`/`X-Forwarded-Proto`.
4. **Env var name mismatch.** The server reads `GOOGLE_OAUTH_CLIENT_ID` /
   `GOOGLE_OAUTH_CLIENT_SECRET`; the repo `.env` defines `GOOGLE_CLIENT_ID` /
   `GOOGLE_CLIENT_SECRET`.

## Owner-confirmed decisions

- Dedicated Postgres container on gravebuster (pgvector/pg16).
- Keep `main` as the agent/auto-merge branch; add a `production` branch.
- Promotion is a PR from `main` into `production`, merged by the owner.
- Deploy trigger is a pull-based systemd timer polling `origin/production`.
- Secrets are copied to gravebuster over SSH; nothing secret enters GitHub.
- Test environment is Podman in WSL on the dev machine.
- Google sign-in reuses the existing client id; the missing callback is
  implemented as part of this work.

## Design

Spec: `docs/superpowers/specs/2026-10-01-octo-gravebuster-deployment-design.md`

## Owner actions required

- Add `https://octodb.design-bakery.com/api/auth/google/callback` as an
  authorized redirect URI on the existing Google OAuth client.
- Add the tunnel hostname in the Zero Trust dashboard (the repo's Cloudflare
  tokens both fail `/user/tokens/verify` with code 1000).

## Out of scope

Schema-migration tooling for a live database, scale-out/multiple nodes
(Issue #14), and rotating the expired Cloudflare tokens.
