# Issue #45: Host Octo on gravebuster with a production branch and gated CI/CD

- State: closed (2026-10-01)
- Opened by Pukujan on 2026-10-01
- Original: https://github.com/Pukujan-lab/octo-database/issues/45

## Goal

Host Octo's frontend and backend as containers on gravebuster, reachable at
`octodb.design-bakery.com` through the existing Cloudflare tunnel, with a CI/CD
path that cannot break the running service and a `production` branch the owner
promotes to deliberately.

Design spec: `docs/superpowers/specs/2026-10-01-octo-gravebuster-deployment-design.md` (PR #44)

## Blocking defects found in the current code

1. **Google sign-in is broken, not merely unconfigured.** `src/server/index.ts:465`
   redirects to Google with `redirect_uri=${url.origin}/api/auth/google/callback`,
   but no route handles that callback. The complete route list contains
   `/api/auth/google` and `/api/auth/guest` and nothing else.
2. **The server serves no frontend.** `src/server/index.ts` is API-only (`/api/*`,
   `/health`). Vite builds `dist/`, but nothing serves it.
3. **The redirect URI is computed from the wrong origin.** `url.origin` derives
   from the hardcoded `http://localhost:${PORT}` base (`index.ts:436`); nothing
   reads `X-Forwarded-Host`/`X-Forwarded-Proto`.
4. **The env var names do not match.** The server reads `GOOGLE_OAUTH_CLIENT_ID`
   and `GOOGLE_OAUTH_CLIENT_SECRET`; the repo `.env` defines `GOOGLE_CLIENT_ID`
   and `GOOGLE_CLIENT_SECRET`.

## Owner-confirmed decisions

- Dedicated Postgres container on gravebuster (`pgvector/pgvector:pg16`).
- Keep `main` as the agent/auto-merge branch; add a long-lived `production` branch.
- Promotion is a PR from `main` into `production`, merged by the owner.
- Deploy trigger is a pull-based systemd timer polling `origin/production`.
- Secrets are copied to gravebuster over SSH; nothing secret enters GitHub.
- Test environment is Podman in WSL on the dev machine.
- Google sign-in reuses the existing client id; the missing callback is implemented
  as part of this work.

## Scope

- `deploy/gravebuster/` stack: Caddy web, Node API, pgvector Postgres.
- Application changes: OAuth callback, `GET /api/me`, frontend token pickup,
  `PUBLIC_BASE_URL`/forwarded-header origin fix.
- `gates.yml` extended to `production`; `auto-merge.yml` unchanged.
- `deploy/local/` Podman test stack.
- `docs/self-hosting.md` runbook.

## Owner actions required

- Add `https://octodb.design-bakery.com/api/auth/google/callback` as an authorized
  redirect URI on the existing Google OAuth client.
- Add the tunnel hostname in the Zero Trust dashboard (the repo's
  `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ZONE_API_TOKEN` both fail
  `/user/tokens/verify` with error code 1000).
- Confirm port 8090 is free on gravebuster.

## Out of scope

Schema-migration tooling for a live database, scale-out/multiple API nodes
(Issue #14), and rotating the expired Cloudflare tokens.
