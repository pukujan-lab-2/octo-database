## Summary
Implements the gravebuster hosting stack and resolves the blocking application defects specified in #43 and the approved design spec:
- Google OAuth callback (\GET /api/auth/google/callback\) exchanging code, decoding verified claims, and upserting principal into PostgreSQL with deterministic UUID from Google sub.
- Current-principal endpoint (\GET /api/me\) returning authenticated principal and API key info.
- Frontend token pickup in \src/main.tsx\ extracting URL fragment (\#token=...\), persisting to \octo_token\, and resolving principal via \/api/me\.
- Dynamic and configured public base URL resolution (\PUBLIC_BASE_URL\ and \X-Forwarded-*\ headers) for tunnel compatibility.
- Static Vite asset serving fallback directly in Node platform server when \dist/\ exists.
- Three-container Docker Compose deployment stack in \deploy/gravebuster/\: Caddy reverse-proxy web tier, Node API tier, and pgvector Postgres database with auth scaffold initdb.
- Deploy, rollback, and systemd 5-minute autodeploy timer scripts.
- Local Podman compose test stack in \deploy/local/\.
- Full runbook in \docs/self-hosting.md\.
- Extended \gates.yml\ validation trigger to \production\ branch.
- Documented AGENTS.md auto-merge carve-out for owner-gated production branch.
