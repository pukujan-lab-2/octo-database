## Summary
Adopts the 3-plane observational issue protocol and automated triage workflow directly in Octo, implements platform owner elevation with a dedicated Platform Admin modal, and resolves race conditions in workspace loading and context selection.

Addresses observational issue #52 and aligns with upstream PCM protocol RFC (Pukujan/project-continuity-modules#224).

## Changes
1. **GitHub Observational Issue System**:
   - Added `.github/ISSUE_TEMPLATE/observational-issue.yml`: 3 planes (Plane 1: Lead Owner P1–20, Plane 2: Collaborator P20–40, Plane 3: Community P40–100), mandatory provenance, reproducibility, citations, risk/blocker rating, and non-binding proposal semantics.
   - Added `.github/workflows/issue-triage.yml`: automated workflow for labeling planes, priority tiers, and proposal tags.
