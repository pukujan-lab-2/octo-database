## Description
Fixes edge-case defects identified during skeptical review of the 3-plane observational issue system and platform administration adoption:
1. **False-Positive Plane Misclassification**:
   - In \.github/workflows/issue-triage.yml\, searching the entire issue body for \Lead Owner\ caused Plane 2 or Plane 3 issues that mentioned the lead owner in descriptive text to be erroneously triaged into Plane 1 (\plane:lead-owner\) and clamped to priorities 1-20.
   - Hardened plane parsing to isolate the \### Contributor Plane\ / \### Observational Plane\ section, and scoped priority parsing to prevent matching arbitrary numbers from descriptive prose.
   - Extracted shared parser logic in \src/triage/issue-parser.ts\ with 5 thorough unit tests in \	ests/unit/issue-triage.test.ts\.
2. **Guest Login Race Condition / Dropped Active Context**:
   - In \src/main.tsx\, guest login called \handleSelectWorkspace(wsSummary.id, 'owner')\ while \sessionToken\ in state was still null, causing it to return early without creating \ctiveContext\.
   - Added \	okenOverride\ and \principalOverride\ parameters to \handleSelectWorkspace\, \efreshShares\, and \efreshOperations\, ensuring synchronous active context selection and resource loading during guest authentication.
3. **Missing Avatar URL in Server Token Authenticator**:
   - In \src/server/index.ts\, \uthenticateRequest\ queried \octo.principals\ without \vatar_url\ and returned \vatarUrl: null\. Updated queries to include \vatar_url\ so avatars display properly.
4. **Upstream ACS Issue Filing**:
   - Filed missing observational issue tracking in \Pukujan/agent-custom-setup#51\ and cross-referenced with PCM#224 and Octo#52.
