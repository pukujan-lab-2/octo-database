# Issue #62: Fix dashboard double-padding and Windows server start guard

- State: closed (2026-10-04)
- Opened by Pukujan on 2026-10-02
- Original: https://github.com/Pukujan-lab/octo-database/issues/62
- Labels: bug

Found while bringing the app up locally to verify the frontend.

## Defects

1. **Frontend double-padding.** The Active Workspace metadata card set `p: 2` on the `Card` *and* rendered a `CardContent` (default 16px), so its content sat at 33px while every sibling card sat at 17px — visible as an indented workspace header. The Gallery header had the same defect (`py: 2` inside an already-padded `CardContent`).

2. **Server never starts on Windows.** `src/server/index.ts` gated `server.listen()` on `process.argv[1]?.endsWith('server/index.ts')`. On Windows `argv[1]` is a backslash path, so the guard was always false and the process exited silently with no listener — `npm run server` and the Playwright `webServer` could not start the API on Windows.

## Fix

- Remove the stacked padding on both cards; all cards now align at 17px (verified by DOM measurement).
- Compare the entry path on `path.basename` so the direct-run guard is separator-agnostic.
