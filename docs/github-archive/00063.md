## Summary
Two defects found while bringing the app up locally to check the frontend:

- **Dashboard double padding.** The Active Workspace metadata card set `p: 2` on the `Card` *and* rendered a `CardContent` (default 16px), so its content sat at 33px while every sibling card sat at 17px — visible as an indented workspace header. The Gallery header had the same defect (`py: 2` inside an already-padded `CardContent`).
- **Server never started on Windows.** `src/server/index.ts` gated `server.listen()` on `process.argv[1]?.endsWith('server/index.ts')`. On Windows `argv[1]` is a backslash path, so the guard was always false and the process exited silently with no listener — `npm run server` and the Playwright `webServer` could not start the API on Windows.

## Changes
- Remove the stacked padding on both cards; all cards now align at 17px.
- Compare the entry path on `path.basename` so the direct-run guard is separator-agnostic.

## Verification
- DOM measurement of every card's first-child offset: all now `17px L / 17px T` (was 33px for the workspace card).
- Screenshot before/after confirms the alignment.
- `npx tsc --noEmit` passes.
- API `/health` responds locally on Windows after the guard fix.
