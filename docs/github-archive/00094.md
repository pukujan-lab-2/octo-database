## Summary
Three operator tools over the existing HTTP API, each with pure decision logic extracted so it is testable without a network or a real directory walk.

- **`npm run backup`** (`scripts/octo-backup.ts`) — upload-only, incremental backup of Desktop and Downloads into one workspace. Preserves folder structure (paths relative to the source root), prunes machine-generated trees (`node_modules`, `.git`, `__pycache__`, ...) so a real Desktop is not ~90% build output, skips temp/OS-cruft/empty/oversized files, and records a manifest so a re-run uploads only what changed. It never deletes, moves, or renames anything locally, and stores no credentials (token from env).
- **`npm run capture-ops`** (`scripts/capture-ops.ts`) — snapshots repo state and live `/health` into a workspace as operational data.
- **`npm run export-vectors`** (`scripts/export-vectors.ts`) — exports pgvector embeddings as JSONL, to a file or to R2.
- **`npm run production-smoke`** (`scripts/production-smoke.ts`) — read-only hosted-runtime check (HTTPS `/health`, HTML at `/`, a static asset, `401` on an unauthenticated API route); base URL via `OCTO_SMOKE_BASE_URL`.
- `scripts/s3-sink.ts` — a local S3-compatible sink so the export path is verifiable without cloud credentials.
