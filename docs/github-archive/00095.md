## Summary
Exposes the Octo workspace surface as MCP tools so an agent drives Octo with the same token a human or script uses.

- **Account-wide key** (`octo_live_acc_`) → manages every workspace the principal belongs to.
- **Workspace-scoped key** (`octo_live_ws_`) → confined to its own workspace by the server.
- The adapter is a **thin client of the public API**: it holds no database or provider credentials and adds no policy of its own, so an API refusal surfaces as a tool error rather than a silent success.

Tools: `whoami`, `list_workspaces`, `list_files`, `upload_file`, `query_workspace`. Run with `npm run mcp` (stdio); configure via `OCTO_MCP_TOKEN` and `OCTO_MCP_BASE_URL`.
