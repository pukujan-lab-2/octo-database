## What
`scripts/octo-backup.ts` skipped a configured source whose folder is missing or redirected (common for `Downloads` on Windows) with a one-line stderr note, while the JSON summary still listed that source under `"sources"` as though it had been backed up. For a backup tool this silent false coverage is the worst failure mode: the run reports "downloads" covered when nothing from Downloads was read.

## Fix
Add a pure `partitionSources` helper to `src/backup/planner.ts` and use it so the summary reports `sources` (scanned) and a new `missingSources` field honestly. The per-source skip note is unchanged.

- Manual proof against a fixture with one present and one absent source: `sources: ["present"]`, `missingSources: ["absent"]`, stderr note retained.
