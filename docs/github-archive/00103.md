## Summary
- A malformed `fileId`, `jobId`, `shareId`, or `workspaceId` from a path or query went straight to a Postgres uuid column, raised `22P02`, and the outer handler answered `500 INTERNAL_SERVER_ERROR: <raw database text>` — a wrong status for a client mistake and a leak of internal detail.
- Adds a `requireUuid` helper and guards every route that reads an id from a path or query, returning a clean 400 before any database call. Reuses the existing `INVALID_WORKSPACE_ID` shape for `workspaceId` and a generic `INVALID_IDENTIFIER` for the other fields.
- Extends the capability-discovery `INVALID_WORKSPACE_ID` contract to the file, gallery, activity, job, and share routes, plus the media-authorization path (which now fails closed rather than querying with a malformed id).
