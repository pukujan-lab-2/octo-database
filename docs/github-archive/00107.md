## Summary
- `data-octo-system` (the attribute that selects the palette) was set only at the end of `renderApp`, so it applied after signing in but never on the login or public-share screens.
- A returning user who chose the light "paper" theme still got a dark login card on a fresh load — their theme didn't stick until they entered the app.
- Set the attribute in `render()`, which every screen flows through, so the chosen theme applies from first paint.
