## Summary
- `clearSession()` cleared the token, principal, and workspace data but left `state.oneTimeSecret`, `state.oneTimeLabel`, and `state.shareUrl` in memory.
- Those are one-time credentials (a minted API-key secret, a read-only share link). After sign-out, the next person to sign in on the same machine saw the prior session's secret rendered in the Access view's one-time notice — a credential disclosed to a different session.
- Sign-out now clears the one-time material with the rest of the session.
