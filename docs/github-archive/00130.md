## Summary

Slice 16 (#124). After Slice 15 stamps creation with the human confirmation secret, this adds a second, independent guard: a **non-owner principal may create at most one workspace per rolling day**. Bounds spam from a compromised browser session that still holds the secret.

- Count is **derived** from `octo.workspaces` (`created_by`, `created_at`) — no counter table.
- The **auto-provisioned sign-in sandbox** is excluded via a new `auto_provisioned` column, so a brand-new account can still create its first project workspace.
- The **platform owner is exempt** (the human override until the Admin Console #52 exists).
- Refusal is a clean `429 WORKSPACE_DAILY_LIMIT`, shown in the create modal.
