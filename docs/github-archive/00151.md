## Summary

- Adds `OCTO_SESSION_TTL_SECONDS` (default unchanged at 7 days) so a deployment can shorten or lengthen session lifetime without a code change. Unset, non-numeric, or non-positive falls back to the default.
- Adds a client-side 30-minute idle lock and proactive expiry detection. A saved token past its expiry no longer boots straight into a dead session.
- Both end paths (server 401 and client watchdog) now land on the login screen with a clear "Your session expired. Please sign in again." notice instead of a silent drop.
- New `src/lib/session-expiry.ts` reads the expiry the server already embedded in the token — pure string parsing, no node `crypto`, so the signing module stays out of the browser bundle.
- Unit tests for the configurable TTL and the client expiry reader; `.env.example` files document the new variable.
