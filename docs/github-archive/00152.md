## Summary

The production env template (`deploy/gravebuster/.env.example`) carried no `OCTO_EMBEDDING_*` entries. Production therefore could not be configured for embeddings, and the one query-shaped surface Octo exposes — `POST /api/rag/query`, plus ingest via `POST /api/rag/documents` — returns `503 EMBEDDING_PROVIDER_NOT_CONFIGURED` (`src/rag/embeddings.ts:25-31`, `src/server/index.ts:2950-2956`).

This adds the four entries, mirroring the root `.env.example`, with a note that `OCTO_EMBEDDING_DIMENSIONS` must match the Slice 8 migration's vector width (1536).
