## What

A `query_graph` MCP tool. Agents reach `POST /api/graph/query` with the same Octo key every other tool uses.

## Why it adds no new authority

The MCP adapter is a thin client of the public API: it holds no engine password and duplicates no server policy. The graph name is derived server-side from the authenticated workspace UUID, and the route applies the same four checks as every other capability (scope → key-workspace match → membership → read-only path). So this tool widens nothing — it makes an already-mediated read reachable from MCP.

`params` is restricted to scalars (string/number/boolean/null), matching exactly what the route forwards to the engine.

## Failure honesty

An unconfigured engine answers `503 GRAPH_NOT_CONFIGURED`, surfaced as a tool error rather than an empty success that would read as "the workspace has no graph".
