## Summary

- Publishes one active file by copying it into a separate public bucket (or a local public directory when `OCTO_STORAGE_BACKEND=local`). The stable URL is the public base plus the file id. Unpublish deletes that copy and leaves the private bytes.
- `files.publish` and `files.unpublish` require scope `write` and role `operator`, so a program-write key can do both. A missing public target is 503, a non-active archive state is 409, and a failed copy or delete does not clear the catalog incorrectly.
- The private bucket stays private. No dashboard page, new scope, or second credential pair.

Fixes #175.
