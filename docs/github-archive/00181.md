On a phone, creating an API key pushed the confirmation code, the Generate button, and the one-time secret off the screen.

There was no helper that keeps a control in view. `notify()` only flashes a toast. The form now stacks to the width of the screen, the page scrolls under the header instead of underneath it, and a small `reveal()` brings the button into view while creating and the secret into view after it is minted.
