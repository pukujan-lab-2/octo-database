## Summary
- Adds `deploy/mac/` so the existing host-agnostic compose stack (`deploy/gravebuster/docker-compose.yml`) can run on a macOS host, used while the Linux box (gravebuster) is offline.
- `backup.sh` — `pg_dump -Fc` of the whole `octo-db` cluster to a timestamped archive, prunes old local copies, copies offsite via `rclone` when an `r2:` remote exists. Verified restorable into a scratch database.
- `install-launchd.sh` — replaces `deploy/gravebuster/systemd/` with user LaunchAgents: autodeploy poller every 300s + daily backup at 03:30. No sudo.

## Why
The owner directed hosting Octo on a MacBook Pro. The compose file, `deploy.sh`, `migrate.sh`, and `autodeploy.sh` are already host-agnostic; only the systemd units and the `docker-compose.edge.yml` Cloudflare overlay are Linux-specific. This adds the macOS scheduling + backup equivalent without touching the existing Linux path.
