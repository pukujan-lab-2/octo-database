`docker run -e TUNNEL_TOKEN` (no `=value`) copies the variable from the docker client's environment. `tunnel.sh` assigned `TUNNEL_TOKEN` from the host `.env` but never exported it, so the connector container never received the token and exited immediately — the public hostname stayed down even though the script reported "started".

Export the variable before `docker run` so the connector starts as documented.

Verified on the Mac host: with the export, `octo-cloudflared` registers 4 tunnel connections and `https://octodb.design-bakery.com/` returns 200.
