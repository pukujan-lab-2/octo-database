## Summary
- The platform-owner exemption from the Slice 16 workspace-creation limit is keyed on `PLATFORM_OWNER_EMAIL` (`src/server/db.ts:246`), but the variable was never listed in `deploy/gravebuster/.env.example`.
- A host that never set it — as the live Mac host did not — treats the owner as an ordinary principal, so the owner gets `429 WORKSPACE_DAILY_LIMIT` on their second workspace of the day.
- Adds the variable with a comment explaining what it grants and the failure mode when it is unset.

No code change: the exemption itself is already implemented (`enforceDailyLimit: !auth.principal.isPlatformOwner`). This only stops the next host from silently omitting the variable.
