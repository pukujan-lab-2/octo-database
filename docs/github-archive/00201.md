## Summary

Two macOS-host deploy fixes.

**1. Executable bits (original).** `deploy/mac/backup.sh`, `install-launchd.sh`, and `tunnel.sh` were committed mode `100644`. launchd refuses a non-executable `ProgramArguments` with `EX_CONFIG (78)`, so the backup agent had never run. Set the bit in the git index (a host-only `chmod` is stripped by autodeploy's `git reset --hard`).

**2. Backup retention.** The prune step globbed `octo-<stamp>-files-*.tar.gz`, but the archive is written as `octo-files-<stamp>.tar.gz` — the glob never matched, so **uploaded-file archives accumulated forever**. The archive name is now derived from the dump name and removed alongside it. `OCTO_BACKUP_KEEP` default drops from `14` to `1`: one rolling copy instead of a 14-deep stack of full snapshots.
