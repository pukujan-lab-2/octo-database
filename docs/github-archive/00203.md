## Summary
- Adds `src/server/mcp-http.ts`, which serves the existing 20-tool MCP server over the SDK's Streamable HTTP transport, stateless (fresh `McpServer` + transport per request, each wired to an `OctoApi` carrying the caller's own token).
- Routes `/mcp` (and `/mcp/<key>`) in `src/server/index.ts` through the existing `authenticateRequest`, so the same bearer keys and RLS binding apply.
- Proxies `/mcp*` to `octo-api:3001` in `deploy/gravebuster/Caddyfile`.

## Why
Octo's MCP adapter (`scripts/octo-mcp.ts` → `src/mcp/server.ts`) was stdio-only — a local process a hosted client like ChatGPT cannot reach. ChatGPT custom connectors offer only OAuth or no authentication (no bearer field), so the key may ride either as a bearer header (`/mcp`) or in the path (`/mcp/<key>`); both verify through the same code path.
