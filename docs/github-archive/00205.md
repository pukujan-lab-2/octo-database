## Summary
- `/api/auth/guest` now requires a Cloudflare Turnstile token; `/health` advertises `turnstileSiteKey` and the login screen renders the widget and sends its token.
- Server verifies at `challenges.cloudflare.com/turnstile/v0/siteverify`, using `CF-Connecting-IP` / `X-Forwarded-For` for `remoteip`.
- Fails open when `TURNSTILE_SECRET_KEY` is unset (CI, local dev, and the E2E suite that drives guest login keep working); arms only where the secret is set.
- `.env.example` and `deploy/gravebuster/.env.example` document both vars.

## Why
Guest login mints a principal + workspace with no challenge, so a script can create unlimited empty workspaces. This closes the anonymous path only — API-key and Google sign-in are untouched.
