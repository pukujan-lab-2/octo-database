## Bugs found by driving the app

Both were caught by the e2e suite and fixed here, not worked around:

1. **Public share viewer crashed** — `MediaCards` called `useOcto()` unconditionally, but `PublicShare` renders outside `OctoProvider`. Split into a pure `MediaGrid` plus an `InteractiveMediaGrid` wrapper; `PublicShare` passes `interactive={false}`.
2. **MFA recovery modal left an orphaned scrim** — Done cleared the codes but never closed the modal, so a fixed-position `.modal-scrim` swallowed every subsequent click (`mfa-step-up.spec.ts` hung on 169 retries). Now clears and closes, matching the legacy `done-recovery` handler.

Also restored the mobile auto-scroll the legacy shell did with `reveal('.access-create-form .button','end')`: the key form is tall, and on a 390px phone the confirm code and submit button land under the fold. `Access.tsx` now scrolls the submit button into view once the code draws.
