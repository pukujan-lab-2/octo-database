## What this PR does

- **`docs/ARCHITECTURE.md`** — the modular-monolith shape, the layer rule (`routes → services/stores → db-core → lib → types`), a "where does new code go" table, and the two invariants that break *silently*: the `index.ts` import order that keeps the `.env` load after `db.ts`, and the `src/server/db` barrel that `ops-events-500-capture.test.ts` mocks by module id.
- **`AGENTS.md`** — the short version agents read first.
- **`.dependency-cruiser.cjs` + `npm run lint:imports`**, wired into the required `gates` check. A boundary violation now fails CI rather than surviving review.
- **Two 10-line edge fixes** so the rules ship with **no carve-outs**: `hashApiKeySecret` → `src/lib/secret-hash.ts` (so `src/lib/mfa.ts` stops reaching up into `src/api`), and the graph-projection types → `src/types/graph.ts` (so `src/jobs/worker.ts` stops importing from `src/server/db`). Both keep their old import paths working via re-export, so no caller churns.

## Deliberate non-goals

No framework (Express/Fastify/Nest), no DI container, no ORM, no event bus. The raw-`http` dispatch loop stays. No container collapse. The problem is co-location, not style.
