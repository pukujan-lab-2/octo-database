## Summary

- Adds a Keys view next to Access, with an account cabinet and a cabinet for the current workspace.
- Stores logins, tokens, URLs, and notes. Every item requires a description. Secrets use the existing MFA envelope (`OCTO_MFA_SECRET`).
- The owner mints a temporary grant from the dashboard (default 24 hours, any whole number from 5 through 72). Opening that grant returns one cabinet. A decoy grant uses the same response and does not return the stored secret.
- Health checks mark stale items. Items that have been stale for 14 days are deleted on the next check.
