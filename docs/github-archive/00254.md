## Summary
- Adds `octo.vault_routes`: one row per vendor-facing base URL for a stored credential, with `auth_scheme` (`bearer`, `x-api-key`, `basic`, `query`, `body_json`, `path`), the header/param/JSON-leaf/path template it needs, and `ok | unauthorized | forbidden_group | unreachable` health.
- Adds `octo.vault_leases`: the per-agent working key (`octo_tmp_`), one active lease per `(grant, item)`, cascading from its grant. Revoking the grant kills its leases; expiry only stops the key resolving.
- `octo.consume_vault_lease(hash, route_key)` resolves a key and its route in one SECURITY DEFINER call, so a key can never be paired with another item's route.
- `vault_items.url_kind` distinguishes `api_base | api_endpoint | docs | console | cors | s3_endpoint`.
- Policy helpers: `parseLeaseDays` (default 15, 1–30), `parseVaultRoute`, `parseUrlKind`, `routeKeySlug`.

No behavior change: nothing mints or reads a lease yet. Follow-ups add route CRUD, minting, the egress relay, health, UI, and docs.
