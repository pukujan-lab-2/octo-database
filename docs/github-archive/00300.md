### Affected App, Adopter, Users, or Systems
Octo's MCP adapter, MCP clients connecting to Octo (including ChatGPT), and agents needing subsets of workspace database, files, graph, retrieval, and analytics capabilities.

### Observed Consequence and Workaround
**Observed:** At revision `a17942d`, `src/mcp/server.ts` registers **29** named MCP tools plus server orientation instructions. The currently connected ChatGPT Octo app exposes **25** tools (the four analytics tools are absent); that specific difference is also tracked separately in a related analytics observation. The adapter directly returns pretty-printed JSON through `asText`.

**Not established:** No measured token overhead, inference-cost regression, tool-selection error, or large-scale production incident has been demonstrated. Model-context inclusion of every tool definition depends on the **client/host**, not merely on Octo registering tools.

**Potential consequence if the catalog grows:** Hosts that inline all descriptions and schemas may spend more context on tool definitions and large returned datasets; relevance/selection may deteriorate.

**Workaround:** Clients can scope which tools are advertised to an agent and cap/paginate result data; use direct API/SDK for heavy jobs, then return only compact results or artifact references.
