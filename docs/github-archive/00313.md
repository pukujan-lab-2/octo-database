## Summary
- The hybrid lexical arm tokenized documents with `to_tsvector('english', content)`, which keeps an entire URL path as one lexeme. A query naming an identifier that only appears inside a URL therefore produced lexemes the document never contained.
- Fix: normalize non-alphanumeric runs to spaces before tokenizing, on **both** the document and query sides so the arms stay symmetric.
- Adds MR-5 to the e2e suite, which reproduces the production shape.
