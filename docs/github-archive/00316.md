## Summary

The section-2 band on the signed-out homepage had a hand-rolled 2D canvas node mesh. It now carries the actual three.js singularity from `acs-constellation`:

- horizon sphere, photon ring, fresnel lensing rim, fbm gas shell, two counter-rotating accretion planes, three depth-tested halo sprites
- a screen-space lensing pass (EffectComposer: RenderPass → ShaderPass → OutputPass) that bends the starfield and stars behind the hole
- an additive starfield on two shells, drifting at different rates, with a desktop-only scroll parallax

**Palette.** Every colour-bearing uniform is read from the design tokens on `<html>`, so the hole recolours with all six design systems and both light/dark variants through the same `MutationObserver` path as the rest of the page. The disk ramps cyan (`--chart-2`) → violet (`--chart-5`) → amber (`--warning`); the lime signal colour mixed with amber produced olive, so the signal colour is used for the photon ring and halo instead.

**Interaction.** Drag in the middle of the band to orbit; the outer 20% of each axis (min 44px) stays the page's so a phone can scroll past a full-bleed band. `touch-action` is latched on pointerdown, since Chromium takes it from the style committed before the gesture starts.

**Also fixed:** the copy overlay wrapper had `pointer-events` on, so a drag over the band selected the headline instead of orbiting the camera.
