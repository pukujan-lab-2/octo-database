## What

Adds a **Services** item to the workspace sidebar with an Open button for traces and evals (Phoenix) and for deploy. Octo builds no dashboard for either tool; the button opens the tool's own UI in a new tab.

- `GET /api/services` (authenticated) returns the links from server config: `OCTO_PHOENIX_URL`, `OCTO_DEPLOY_URL`, `OCTO_DEPLOY_TOOL` (display name). Only http(s) URLs are returned.
- A service whose URL is unset shows as **Not set up** with a disabled button, so nothing is linked until it is hosted.
