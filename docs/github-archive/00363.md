Issues pile up because no merged PR uses a closing verb. `close-on-merge-caller.yml` (OIO) already closes an issue log when a merged PR says `Closes #n`, but the last 40 merged PRs never did.

This adds one rule to AGENTS.md:
- PRs that complete an issue say `Closes #n`; partial work says `Refs #n`.
- Search open issues and comment on a match before filing a new log.
