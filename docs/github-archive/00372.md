`scripts/octo-env-pull.mjs` is a single Node file with no dependencies. With an owner agent key it reads the vault through the existing `/api/vault/items` routes and writes a `.env` file, so no server change is needed.

- **Which labels it pulls:** the labels already in the file. `--add LABEL` adds one, and `--all` pulls every env-shaped vault label.
- **Local block:** lines between `# >>> local` and `# <<< local` are kept as they are and never pulled. That block holds the pull key itself and values that stay on one machine.
- **`--check`:** compares the file with the vault and prints only the names of labels that differ.
- **Safety:** a label missing from the vault keeps its current value. Each write saves `FILE.prev` first and sets the file to 600.
