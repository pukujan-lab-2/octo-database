Behind cloudflared, Caddy logs every request as the tunnel container (172.21.0.3), and that is also the address octo-api sees. This PR:

- trusts `Cf-Connecting-Ip` / `X-Forwarded-For` only from private-range peers (`trusted_proxies static private_ranges`);
- switches the access log to JSON so CrowdSec on the Pro (server-management#17 phase 6) can parse it.

After this, `client_ip` in the log and the X-Forwarded-For header that reaches octo-api carry the caller's address. That is the experiment in #338 H2. Validated with `caddy validate` on caddy:2-alpine (v2.11).
