Each place that uses Octo can now hold its own key.

- **Vault leases:** minting a lease revoked every other live lease for the same grant and item. Two consumers of one secret (the ABA builds on the Pro and nyc-map-agent on gravebuster) kept revoking each other, which broke nyc-map chat. Mints are now independent; each lease lives until it expires or is revoked.
- **Account-wide keys:** the one-per-principal limit (`uq_api_keys_account_wide` and the `ACCOUNT_KEY_EXISTS` check) is dropped, so each machine or agent gets its own named key. `OCTO_OWNER_AGENT_KEYS` already takes a list.

Migration `20261030030000_multiple_keys.sql` drops both unique indexes and keeps a plain index for lease lookups.
