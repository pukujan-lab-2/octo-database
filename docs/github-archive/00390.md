## Later, when history tables grow

Old rows that are rarely read (file versions, `agent_key_uses`, logs) can move out of Postgres into zstd Parquet files on R2 (roughly 10x smaller), queried with DuckDB only when needed (`pg_parquet` / `pg_duckdb`). Related: #341 (analytics over Parquet).

Today `octo.agent_key_uses` is 25 MB and `document_versions` 87 MB (Pro, 2026-10-31), so this waits until those tables are large.
