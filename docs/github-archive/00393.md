- State: open

### Summary

The workspace dashboard has no way to see two things the owner wants to watch: **retrieval (vectors)** and **deployments**. Owner direction 2026-10-31: add both views and have **ABA (app-builder-automation)** build them.

Today the portal views are Overview, Files, Gallery, Operations (jobs/failures), Services, Access, Vault and Analytics (`frontend/src/views/`, checked at `origin/main` 2026-10-31). No view mentions chunks, vectors or embeddings, and nothing shows deploys.

### What each view shows

**Retrieval** (per workspace):
- documents indexed, chunks, vectors, and their size on disk;
- embedding model and dimensions in use, and which reader/reranker answered recently (Windows / Pro);
- ingest progress: queued, embedding, done, failed (from the existing job tables);
- a search box that runs a query and shows the top chunks with their scores, with rerank on/off.

**Deployments** (per workspace, reads the owner's Komodo through the vault key, per #343):
- each app's stack: running or not, server, image/commit, last deploy time;
- recent deploys with their logs;
- buttons for deploy and rollback once #343's verbs exist (read-only until then).

### Scope notes

- Reads existing data first; any missing endpoint is the smallest one that feeds the view.
- Deploy buttons depend on #343. The read-only status part needs only the owner's Komodo URL + API key in the vault.
