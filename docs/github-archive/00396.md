## Cause

As the request role, row-level security on `chunks`, `embeddings`, `documents` and `document_versions` calls `octo.is_workspace_member(workspace_id)` for every row. That helper is `SECURITY DEFINER`, so Postgres can't inline or cache it, and `match_chunks_hybrid` paid it for every row of the workspace in both arms.

## Fix

New migration: `match_chunks_hybrid` becomes `SECURITY DEFINER` (`search_path = octo, public, pg_temp`) and applies the same two checks once: the caller is a member of `target_workspace`, and `request.workspace_id` is unset or equal to it. Every table access inside is already scoped to `target_workspace`.
