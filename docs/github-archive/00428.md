This repository's auto-merge workflow armed every same-repository pull request without checking who wrote it, so a future collaborator's pull request would merge with no review.

## Human outcome

Only the owner's pull requests (and those of the owner's agents, which use the owner's account) merge themselves. To trust someone later, add their login to the repository variable `AUTO_MERGE_AUTHORS`.

## Before and after

| | Before | After |
|---|---|---|
| Owner's pull request | Armed | Armed |
| Anyone else's, or after an untrusted push | Armed | Not armed (turned off if it was), with a notice |

## Change and scope

`.github/workflows/auto-merge.yml` only: a trust check (repository admin, or listed in `AUTO_MERGE_AUTHORS`) on the pull request's author and the account that pushed.

## What stays unchanged

Draft and fork pull requests are still skipped; auto-merge stays allowed in the repository settings; branch protection is untouched.
