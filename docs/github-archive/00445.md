### Summary

Opening the Phoenix trace viewer asks for a separate email and password, and Octo's UX analytics (Umami) has no MCP tools, so agents can neither read its data nor turn it on.

### Identity and Lineage

- related: #442 (trace reads and MCP tools), #400 (UX analytics)

### Acceptance Criteria

1. The platform owner opens Phoenix from Octo without a Phoenix login. Octo sets a signed, expiring cookie from the signed-in session; the web server checks it with Octo before forwarding to Phoenix and adds Phoenix's own admin token. Anyone else, and any request without the cookie, is refused.
2. MCP has tools to read a workspace's UX analytics state, turn it on, and read its data (stats, pageviews, metrics, events, sessions, replays), each tied to a capability.
3. `docs/consuming-octo.md` covers both.

### Boundaries and Next Action

- Phoenix shows every workspace's project, so only the platform owner gets the viewer through this path. Other members keep the read routes from #442.
- Phoenix keeps its own login for anyone who reaches it another way.
- Next action: open the pull request.

### Symptoms

1. On 2026-11-01 the Phoenix log showed `/phoenix/login` and 401s on `/phoenix/graphql` for browser visits.
2. `src/mcp/server.ts` has no UX analytics tool, although `ux_analytics.enable` and `ux_analytics.link` are in the capabilities list.

### Hypotheses (unverified)

- **H1:** Phoenix serves its web app when the request carries the admin bearer token. Would refute: a 401 on its web calls. A GraphQL call with that token on 2026-11-01 answered 200 as `system@localhost`.

### Counter-signal

The admin token reaches every workspace's traces, so a mistake in the cookie check would expose all of them.

### Honest Caveat

Umami has no website yet on production, so its read endpoints were not probed live.

### Problems vs Gaps

- Problem: a second login for a tool Octo already fronts.
- Gap: no agent access to UX analytics.

### Proposal *(proposal)*

A signed cookie from the Octo session, a forward-auth check in the web server, the admin token added at the proxy, and MCP tools for UX analytics.
