# PR #451: Pin Sablier 1.19.1, which stops containers whose session expired

Sablier 1.18.0 can drop an expired session without stopping its container, which then runs forever.

## Problem and consequence

That bug is sablierapp/sablier#1110, reported on the same setup we use: the Caddy plugin with the Docker provider. With 1.18.0, Phoenix or the embedder can stay up after its idle time, so the memory is never freed.

## What changes

`docker-compose.vps.yml` pins `sablierapp/sablier:1.19.1`. 1.19.0 has the fix; 1.19.1 only changes docs.

## Before and after

Before: a container can miss its idle stop.
After: the expired session stops its container.

## How to verify

`gates` must pass. After deploy, `octo-sablier` runs 1.19.1, and Phoenix and the embedder stop after 30 idle minutes.

## What stays unchanged

Labels, health checks, Caddy routes and the `http://sablier:10000` address.
